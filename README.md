## 💻 Featured Projects

### [Repository Lens](https://github.com/Ta1siia/repository-lens) · [Live demo](https://repository-lens.onrender.com/)
A Git history analyzer that surfaces hidden dependencies between files — the ones that keep changing together without being linked by the folder structure. Co-change analysis turns the commit history into an interactive D3.js graph; results are cached by commit SHA, and renamed files are tracked through canonical name chains.
*Python · Flask · GitHub API · SQLite · D3.js* – CS50x final project

### [Green Tourism](https://github.com/zeman-dev/Green_tourism_Frontend) · [Live demo](https://green-tourism-frontend.vercel.app/)
A community eco-tourism platform for Ukraine: travel stories, a traveler directory, bookmarks, and personal profiles, backed by a REST API documented in Swagger. Built by an 11-person team through tickets, pull requests, and code review.
**My part:** on the [backend](https://github.com/zeman-dev/Green_tourism_BackEnd), a private paginated endpoint for the current user's stories and profile updates with email-verified address changes; on the frontend, the profile page with tabs, the profile edit page, the footer, and the fix for the bookmark button (auth modal for guests, save request for signed-in users).
*Next.js · React · TypeScript · TanStack Query · Zustand · Node.js · Express · MongoDB · JWT · Cloudinary · Nodemailer*

### [Pet Haven](https://github.com/Ta1siia/pet-haven) · [Live demo](https://ta1siia.github.io/pet-haven/)
A pet adoption website built by a 10-person team that I led: I split the work, maintained the repository and Git workflow, and reviewed every contribution. Modular CSS architecture, mobile-first layout.
*HTML · CSS · JavaScript · Vite*
